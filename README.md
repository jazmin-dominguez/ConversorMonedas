# 💱 Conversor de Monedas

Una aplicación de consola en Java que permite convertir divisas en tiempo real utilizando la [ExchangeRate-API](https://www.exchangerate-api.com/).

## 🚀 Tecnologías Utilizadas
* Java (HttpClient, HttpRequest, HttpResponse)
* [Gson](https://github.com/google/gson) para el análisis de datos JSON.
* Programación Orientada a Objetos (POO).

## 🛠️ Funcionalidades
El menú cuenta con las siguientes opciones de conversión:
1. Dólar a Peso argentino
2. Peso argentino a Dólar
3. Dólar a Real brasileño
4. Real brasileño a Dólar
5. Dólar a Peso colombiano
6. Peso colombiano a Dólar

## ⚙️ Configuración
Para correr este proyecto localmente, necesitas obtener tu propia API Key de ExchangeRate-API y reemplazarla en la clase `Principal.java`.
